Error filtering with ignoreErrors

The ignoreErrors config lists message patterns (strings or regexes) that should be silently dropped before the SDK ships them. Useful for known-noisy browser errors that swamp dashboards without indicating a real problem.

The classic example: "ResizeObserver loop limit exceeded" — fires on most apps using a ResizeObserver, isn't actionable, and isn't a bug in the app's code.
