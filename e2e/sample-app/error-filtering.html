Error filtering with beforeError

The beforeError hook runs at the SDK's entry point for every error — before the error breadcrumb is added, before the lastErrorTimestamp is updated, before deduplication. Returning null drops the error completely; mutating fields on the returned event propagates into the eventual payload.

The classic noise-pattern case: "ResizeObserver loop limit exceeded" — fires on most apps using a ResizeObserver, isn't actionable, and isn't a bug in the app's code.
