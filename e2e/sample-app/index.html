SDK e2e fixture

This page is loaded by Playwright tests. The SDK init reads config from URL params:

  • ?key=... — ingestion key (default e2e)
  • ?tracePropagationTargets=glob,glob — comma-separated globs
  • ?beforeSendDrops=1 — install a beforeSend that returns null
  • ?beforeSendDropMatching=SUBSTR — install a beforeSend that drops errors whose message includes SUBSTR
  • ?beforeSendRedactPattern=REGEX&beforeSendRedactWith=TEXT — install a beforeSend that replaces matches in error.message
  • ?ignoreErrors=foo,bar — comma-separated patterns
