PII redaction via beforeSend

The beforeSend hook receives the mutable error event and can either return it (possibly modified) or return null to drop it entirely. This sample shows a realistic hook that combines two responsibilities most production apps need:

  1. Drop known-noisy browser errors (here, ResizeObserver).
  2. Redact email addresses from every field where they leak.

The redaction touches three fields because a single message can ride through the SDK in three places:

  • event.message — the literal Error message.
  • event.stack — V8 prefixes the stack with "Error: <message>", so the unredacted message re-appears inside it.
  • event.breadcrumbs[].message — the SDK auto-adds an error breadcrumb with the raw message before beforeSend runs, so the original message rides along inside the same payload.
