PII redaction via beforeError + beforeBreadcrumb

The SDK exposes two early-pipeline hooks. Each runs once per event at the SDK's entry point, before any buffering. Returning null drops the event; mutating fields propagates into the eventual payload.

  • beforeError(event) — fires once per error. Redact message, stack, filename; drop known-noisy patterns by returning null.
  • beforeBreadcrumb(breadcrumb) — fires once per breadcrumb, including the SDK's automatic ones. Redact message or data. Breadcrumbs filtered here never enter the buffer, so they ship in neither error payloads nor periodic events payloads.

The split matches where each kind of data flows:

  • event.message and event.stack are error-only fields — handled in beforeError.
  • breadcrumb.message appears both inside error payloads (event.breadcrumbs[]) and inside the 30-second events flush — one beforeBreadcrumb covers both channels.
